# Iyan-Kim UV Mask Tool

Iyan-Kim UV Mask Tool은 Unity Editor에서 Renderer의 **Material Slot**을 기준으로 UV 섬을 선택하고, 선택한 영역을 **PNG 마스크 텍스처**로 내보낼 수 있는 에디터 툴입니다. 복잡한 메쉬의 UV 영역을 외부 페인팅 툴에서 직접 다시 칠하지 않고도, Unity 안에서 필요한 UV 섬을 골라 마스크 이미지를 빠르게 만들 수 있습니다.

VRChat 아바타, 의상, 소품, 모듈형 메쉬처럼 여러 머티리얼 슬롯과 UV 섬을 가진 에셋의 텍스처 작업에 사용하기 좋습니다.



### 기능

- **Material Slot 기반 UV 감지**
  Renderer를 선택한 뒤 Material Slot을 고르면, 해당 슬롯이 사용하는 submesh 삼각형만 읽어 UV 섬을 생성합니다.

- **UV 섬 자동 생성**
  선택한 Material Slot의 UV 삼각형 연결 정보를 기반으로 UV 아일랜드를 자동으로 감지합니다.

- **UV 채널 자동 감지**
  선택된 Material Slot 기준으로 사용 가능한 UV 채널을 감지하고, 적절한 UV 채널을 자동으로 선택합니다.

- **UV 미리보기**
  UV 영역을 툴 창에서 직접 확인할 수 있습니다.
  줌, 패닝, 와이어프레임 표시, 프리뷰 텍스처 표시를 지원합니다.

- **텍스처 미리보기 지원**
  별도 Texture2D를 지정하거나, 선택된 머티리얼의 메인 텍스처를 가져와 UV 위에 겹쳐 볼 수 있습니다.

- **UV 섬 선택**
  UV 미리보기에서 섬 단위로 클릭해 선택할 수 있습니다.
  전체 선택, 반전, 해제를 지원합니다.

- **Face 선택 모드**
  섬 단위가 아니라 개별 Face 단위로 선택할 수 있습니다.

- **Scene View 하이라이트**
  선택한 UV 영역에 대응되는 메쉬 삼각형을 Scene View에서 강조 표시할 수 있습니다.

- **PNG 마스크 내보내기**
  선택한 UV 섬 또는 Face 영역을 PNG 마스크 텍스처로 내보낼 수 있습니다.

- **해상도 프리셋 지원**
  `256`, `512`, `1024`, `2048`, `4096` 해상도 프리셋을 지원합니다.
  사용자 지정 해상도는 최대 `8192`까지 사용할 수 있습니다.

- **색상 설정**
  배경 색상과 선택 영역 색상을 직접 설정할 수 있습니다.

- **알파 포함 옵션**
  PNG 내보내기 시 알파 채널 포함 여부를 설정할 수 있습니다.

- **패딩 옵션**
  선택 영역에 -10부터 10까지 패딩을 적용할 수 있습니다.

- **안티앨리어싱 지원**
  Off, SSAA 2x, SSAA 4x 옵션을 통해 마스크 가장자리를 더 부드럽게 만들 수 있습니다.

- **다국어 UI 지원**
  **한국어, 영어, 일본어** UI를 지원합니다.
  선택한 언어는 Unity EditorPrefs에 저장됩니다.

- **Editor-only 구조**
  에디터 전용 툴이며, 런타임 빌드에는 영향을 주지 않습니다.



### 요구 사항

- Unity **2022.3** 이상
- MeshRenderer 또는 SkinnedMeshRenderer
- UV가 포함된 Mesh
- Material Slot이 있는 Renderer
- Unity Editor 전용 사용
- 별도 VPM 의존성 없음



### 사용 방법

#### 기본 사용법

1. 메뉴에서
   **Iyan-Kim > Tools > UV Island Mask Generator** 를 엽니다.

2. 툴 창의 **렌더러** 필드에 MeshRenderer 또는 SkinnedMeshRenderer를 지정합니다.

3. **Material Slot**에서 마스크를 만들고 싶은 머티리얼 슬롯을 선택합니다.

4. UV 미리보기에서 원하는 UV 섬을 클릭해 선택합니다.

5. 필요에 따라 선택 방식을 조정합니다:
   - **Island** – UV 섬 단위로 선택
   - **Face** – 개별 삼각형 Face 단위로 선택

6. 내보내기 설정을 조정합니다:
   - 해상도
   - 알파 포함 여부
   - 배경 색상
   - 선택 색상
   - 패딩
   - 안티앨리어싱

7. **PNG 내보내기** 버튼을 클릭합니다.

8. 저장 위치를 지정하면 선택한 UV 영역이 PNG 마스크로 저장됩니다.



### 옵션 설명

- **렌더러**
  작업할 MeshRenderer 또는 SkinnedMeshRenderer입니다.
  MeshRenderer의 경우 같은 GameObject에 MeshFilter와 sharedMesh가 있어야 합니다.

- **Material Slot**
  UV 섬을 추출할 머티리얼 슬롯입니다.
  선택한 슬롯에 대응되는 submesh 삼각형만 검사합니다.

- **Mesh**
  현재 선택된 Renderer에서 읽어온 Mesh 이름입니다.

- **Vertices**
  현재 Mesh의 버텍스 개수입니다.

- **Triangles**
  Mesh 전체 삼각형 개수입니다.

- **Material Triangles**
  선택한 Material Slot에 해당하는 삼각형 개수입니다.

- **Islands**
  현재 선택한 Material Slot과 UV 채널에서 감지된 UV 섬 개수입니다.

- **Selectable Faces**
  선택 가능한 Face 개수입니다.

- **UV 미리보기**
  선택한 Material Slot의 UV를 확인하고 직접 선택하는 영역입니다.
  마우스 휠로 확대/축소할 수 있고, 가운데 버튼 또는 Alt + 좌클릭 드래그로 패닝할 수 있습니다.

- **Preview Texture**
  UV 위에 겹쳐볼 텍스처입니다.
  직접 지정하거나 **Use Material Texture** 버튼으로 현재 머티리얼의 메인 텍스처를 가져올 수 있습니다.

- **Show Texture**
  프리뷰 텍스처 표시 여부를 설정합니다.

- **Texture Opacity**
  프리뷰 텍스처의 투명도를 설정합니다.

- **Wireframe**
  UV 와이어프레임 표시 여부를 설정합니다.

- **UV Wireframe Color**
  UV 와이어프레임 색상을 설정합니다.

- **Selection Mode**
  선택 방식을 설정합니다.
  Island 모드는 UV 섬 단위로 선택하고, Face 모드는 개별 삼각형 단위로 선택합니다.

- **전체 선택**
  현재 선택 가능한 모든 UV 섬 또는 Face를 선택합니다.

- **반전**
  현재 선택 상태를 반전합니다.

- **해제**
  현재 선택된 UV 영역을 모두 해제합니다.

- **Scene View에서 선택 삼각형 강조**
  선택한 UV 영역에 대응되는 메쉬 삼각형을 Scene View에서 선으로 강조 표시합니다.

- **해상도**
  내보낼 PNG 마스크의 해상도입니다.
  `256`, `512`, `1024`, `2048`, `4096`, Custom을 선택할 수 있습니다.

- **사용자 해상도**
  Custom 해상도를 사용할 때 직접 입력하는 값입니다.
  최대 `8192`까지 사용할 수 있습니다.

- **알파 포함**
  PNG에 알파 채널을 포함할지 설정합니다.
  끄면 배경색과 선택색이 불투명 처리됩니다.

- **배경 색상**
  선택되지 않은 영역의 색상입니다.

- **선택 색상**
  선택된 UV 영역의 색상입니다.

- **패딩**
  선택 영역을 확장하거나 줄이는 값입니다.
  -10부터 10까지 조정할 수 있습니다.

- **안티앨리어싱**
  마스크 가장자리 품질을 설정합니다.
  Off, SSAA 2x, SSAA 4x를 지원합니다.

- **Language / 한국어 / 日本語**
  창 하단에서 UI 언어를 선택할 수 있습니다:
  - English
  - 한국어
  - 日本語



### 팁

- Material Slot을 먼저 선택한 뒤 UV 섬을 선택해야 원하는 머티리얼 영역만 마스크로 만들 수 있습니다.

- UV 섬 단위로 깔끔하게 나뉜 메쉬일수록 Island 선택 모드가 편합니다.

- 작은 일부 면만 마스크로 만들고 싶다면 Face 선택 모드를 사용하세요.

- 프리뷰 텍스처를 켜면 실제 텍스처 위에서 어떤 영역을 선택하는지 확인하기 쉽습니다.

- 고해상도와 SSAA 4x를 함께 사용하면 메모리 사용량이 커질 수 있습니다.
  경고가 표시되면 해상도나 안티앨리어싱 배율을 낮추는 것이 좋습니다.

- 모델 데이터를 읽지 못하는 경우, 모델 Import Settings에서 **Read/Write**를 활성화해야 할 수 있습니다.

- 패딩을 양수로 주면 선택 영역이 확장되고, 음수로 주면 선택 영역이 줄어듭니다.

- VRChat 아바타의 특정 의상 부위, 장식, 피부 영역, 파츠별 쉐이더 마스크를 만들 때 유용합니다.



### 문제 해결

- 렌더러를 선택했는데 메시를 찾을 수 없습니다
  - MeshRenderer의 경우 같은 GameObject에 MeshFilter가 있는지 확인하세요.
  - MeshFilter에 sharedMesh가 연결되어 있는지 확인하세요.
  - SkinnedMeshRenderer의 경우 sharedMesh가 정상적으로 연결되어 있는지 확인하세요.

- Material Slot이 보이지 않습니다
  - Renderer에 머티리얼 슬롯이 있는지 확인하세요.
  - Mesh의 submesh에 유효한 삼각형이 있는지 확인하세요.
  - 비어 있는 submesh는 목록에서 제외될 수 있습니다.

- 사용 가능한 UV 채널이 없습니다
  - Mesh에 UV가 포함되어 있는지 확인하세요.
  - 선택한 Material Slot에 해당하는 삼각형이 실제 UV 면적을 가지고 있는지 확인하세요.
  - 면적이 0인 UV 삼각형만 있는 채널은 제외될 수 있습니다.

- UV 아일랜드가 생성되지 않습니다
  - UV가 겹쳐 있거나 면적이 0인 삼각형으로 구성되어 있지 않은지 확인하세요.
  - 다른 Material Slot을 선택해 보세요.
  - 다른 UV 채널이 있는 경우 자동 감지 결과를 확인하세요.

- PNG 내보내기 버튼이 비활성화됩니다
  - Renderer와 Material Slot이 정상적으로 선택되어 있는지 확인하세요.
  - UV 섬 또는 Face를 하나 이상 선택했는지 확인하세요.
  - 해상도가 1 이상 8192 이하인지 확인하세요.

- 큰 해상도 내보내기 경고가 표시됩니다
  - 출력 해상도 또는 안티앨리어싱 배율 때문에 실제 작업 해상도가 매우 커진 상태입니다.
  - 메모리 사용량이 커질 수 있으므로 4096 이하 또는 SSAA 배율을 낮춰 다시 시도하세요.

- Scene View 하이라이트가 보이지 않습니다
  - **Scene View에서 선택 삼각형 강조** 옵션이 켜져 있는지 확인하세요.
  - UV 영역을 하나 이상 선택했는지 확인하세요.
  - Scene View가 열려 있는지 확인하세요.
