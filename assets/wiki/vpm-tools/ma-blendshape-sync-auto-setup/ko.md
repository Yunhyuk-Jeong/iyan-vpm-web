# MA Blendshape Sync Auto Setup

MA Blendshape Sync Auto Setup은 Modular Avatar의 **Blendshape Sync** 컴포넌트를 자동으로 설정해주는 Unity 에디터 툴입니다. 소스 오브젝트와 타겟 오브젝트의 블렌드쉐이프 이름을 비교해 공통 블렌드쉐이프를 자동으로 찾고, 타겟 오브젝트에 Modular Avatar Blendshape Sync 설정을 생성합니다.

여러 개의 타겟 메쉬를 한 번에 처리할 수 있어, VRChat 아바타 제작 중 의상, 바디, 얼굴 파츠 등의 블렌드쉐이프 동기화 작업을 빠르게 자동화하는 데 사용하기 좋습니다.



### 기능

- **자동 블렌드쉐이프 감지**
  소스 오브젝트와 타겟 오브젝트의 SkinnedMeshRenderer를 비교해 이름이 같은 블렌드쉐이프를 자동으로 찾습니다.

- **Modular Avatar Blendshape Sync 자동 설정**
  타겟 오브젝트에 Modular Avatar Blendshape Sync 컴포넌트를 추가하고, 공통 블렌드쉐이프 바인딩을 자동으로 생성합니다.

- **다중 타겟 지원**
  여러 개의 타겟 오브젝트를 한 번에 등록하고, 한 번의 작업으로 모두 설정할 수 있습니다.

- **드래그 앤 드롭 지원**
  GameObject를 드롭 영역에 끌어다 놓아 타겟 오브젝트를 쉽게 추가할 수 있습니다.

- **다중 선택 지원**
  Hierarchy에서 여러 오브젝트를 선택한 뒤 한 번에 드래그 앤 드롭할 수 있습니다.

- **하위 오브젝트 포함**
  선택한 오브젝트의 하위에 있는 SkinnedMeshRenderer 오브젝트를 자동으로 탐색해 타겟 목록에 포함할 수 있습니다.

- **공통 블렌드쉐이프 미리보기**
  설정을 적용하기 전에 각 타겟에서 감지된 공통 블렌드쉐이프 목록을 확인할 수 있습니다.

- **중복 오브젝트 필터링**
  이미 등록된 오브젝트는 중복으로 추가되지 않도록 처리됩니다.

- **다국어 UI 지원**
  **한국어, 영어, 일본어** UI를 지원합니다. 기본 언어는 한국어입니다.

- **Undo 지원**
  Unity Undo 시스템과 연동되어, 설정 작업을 되돌릴 수 있습니다.



### 요구 사항

- Unity **2022.3** 이상
- Modular Avatar **1.14.3** 이상
- NDMF
- SkinnedMeshRenderer가 포함된 소스 오브젝트
- SkinnedMeshRenderer가 포함된 하나 이상의 타겟 오브젝트



### 사용 방법

#### 기본 사용법

1. 메뉴에서
   **Iyan-Kim > Tools > Modular Avatar Blendshape Sync Auto Setup** 을 엽니다.

2. 툴 창에서:
   - **소스 오브젝트**에 기준이 될 SkinnedMeshRenderer 오브젝트를 지정합니다.
   - **타겟 오브젝트**에 Blendshape Sync를 설정할 오브젝트를 추가합니다.

3. 타겟 오브젝트는 다음 방법으로 추가할 수 있습니다:
   - 드롭 영역에 GameObject를 드래그 앤 드롭
   - **타겟 오브젝트 추가** 버튼 사용
   - Hierarchy에서 여러 오브젝트를 선택한 뒤 함께 드래그 앤 드롭

4. 필요에 따라 **하위 오브젝트 포함** 옵션을 설정합니다:
   - 켜면 선택한 오브젝트의 하위 SkinnedMeshRenderer까지 자동으로 포함합니다.
   - 끄면 직접 선택한 오브젝트만 타겟으로 추가합니다.

5. 툴 창의 미리보기에서 감지된 공통 블렌드쉐이프를 확인합니다.

6. **블렌드쉐이프 싱크 설정** 버튼을 클릭합니다.

7. 공통 블렌드쉐이프가 있는 모든 타겟 오브젝트에 Modular Avatar Blendshape Sync 설정이 생성됩니다.



### 옵션 설명

- **소스 오브젝트**
  기준이 되는 블렌드쉐이프를 가진 오브젝트입니다.
  이 오브젝트의 SkinnedMeshRenderer에 있는 블렌드쉐이프 이름을 기준으로 타겟과 비교합니다.

- **타겟 오브젝트**
  Modular Avatar Blendshape Sync 컴포넌트가 추가될 오브젝트입니다.
  소스 오브젝트와 이름이 같은 블렌드쉐이프가 있을 경우 자동으로 바인딩됩니다.

- **하위 오브젝트 포함**
  드래그 앤 드롭한 오브젝트의 자식 오브젝트까지 검사합니다.
  SkinnedMeshRenderer가 있는 하위 오브젝트를 자동으로 타겟 목록에 추가할 수 있습니다.

- **드래그 앤 드롭 영역**
  GameObject를 끌어다 놓아 타겟 오브젝트를 추가하는 영역입니다.
  여러 오브젝트를 동시에 드래그해 추가할 수 있습니다.

- **타겟 오브젝트 추가**
  빈 타겟 슬롯을 수동으로 추가합니다.

- **전체 삭제**
  등록된 모든 타겟 오브젝트를 목록에서 제거합니다.

- **발견된 공통 블렌드쉐이프**
  소스와 타겟에 모두 존재하는 블렌드쉐이프 목록을 보여줍니다.
  이 목록에 표시된 블렌드쉐이프만 Blendshape Sync 바인딩으로 생성됩니다.

- **블렌드쉐이프 싱크 설정**
  감지된 공통 블렌드쉐이프를 기준으로 타겟 오브젝트에 Modular Avatar Blendshape Sync 컴포넌트와 바인딩을 생성합니다.

- **Language / 언어 / 言語**
  창 하단에서 UI 언어를 선택할 수 있습니다:
  - 한국어
  - English
  - 日本語



### 팁

- 소스 오브젝트와 타겟 오브젝트의 블렌드쉐이프 이름이 정확히 같아야 자동으로 매칭됩니다.

- 의상이나 바디 메쉬처럼 같은 표정용 블렌드쉐이프를 공유하는 오브젝트에 사용하면 편리합니다.

- 타겟 오브젝트에 이미 Modular Avatar Blendshape Sync 컴포넌트가 있다면, 기존 컴포넌트를 사용하고 바인딩 목록을 새로 설정합니다.

- 하위 오브젝트 포함 옵션을 켜면 의상 루트 오브젝트 하나만 드래그해도 내부 SkinnedMeshRenderer를 한 번에 등록할 수 있습니다.

- 설정 전에 미리보기 목록을 확인하면 어떤 블렌드쉐이프가 실제로 연결될지 미리 알 수 있습니다.

- 중복된 오브젝트는 자동으로 걸러지므로, 여러 번 드래그해도 같은 타겟이 반복 등록되는 일을 줄일 수 있습니다.



### 문제 해결

- 공통 블렌드쉐이프를 찾을 수 없습니다
  - 소스와 타겟 메쉬에 같은 이름의 블렌드쉐이프가 있는지 확인하세요.
  - 대소문자, 공백, 접두사/접미사가 다르면 다른 블렌드쉐이프로 인식됩니다.
  - 타겟 오브젝트에 SkinnedMeshRenderer가 있는지 확인하세요.

- 블렌드쉐이프 싱크 설정 버튼이 비활성화됩니다
  - 소스 오브젝트가 지정되어 있는지 확인하세요.
  - 최소 하나 이상의 유효한 타겟 오브젝트가 있는지 확인하세요.
  - 공통 블렌드쉐이프가 하나 이상 감지되어야 설정 버튼을 사용할 수 있습니다.

- 소스 오브젝트 오류가 표시됩니다
  - 소스 오브젝트에 SkinnedMeshRenderer가 있는지 확인하세요.
  - Mesh가 정상적으로 연결되어 있는지 확인하세요.

- 설정 후 Blendshape Sync가 예상대로 작동하지 않습니다
  - 소스 오브젝트와 타겟 오브젝트가 같은 아바타 계층 안에 있는지 확인하세요.
  - Modular Avatar와 NDMF가 정상적으로 설치되어 있는지 확인하세요.
  - Modular Avatar 빌드 과정에서 컴포넌트가 처리되는 구조인지 확인하세요.

- 드래그 앤 드롭한 오브젝트가 추가되지 않습니다
  - 하위 오브젝트 포함 옵션이 켜져 있을 경우, SkinnedMeshRenderer가 있는 오브젝트만 목록에 추가됩니다.
  - 직접 추가하려면 **타겟 오브젝트 추가** 버튼으로 빈 슬롯을 만든 뒤 수동 지정하세요.
