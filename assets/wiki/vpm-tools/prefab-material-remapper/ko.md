# Prefab Material Remapper

Prefab Material Remapper는 Unity Prefab 에셋 내부의 머티리얼을 **현재 슬롯에 들어있는 머티리얼 이름(Material.name)** 기준으로 일괄 치환해주는 Unity 에디터 툴입니다. FBX Importer의 Material Remapping과 비슷한 흐름을 Prefab 에셋에서도 사용할 수 있도록 만들어졌습니다.

복잡한 프리팹, VRChat 아바타, 의상 프리팹처럼 여러 Renderer와 머티리얼 슬롯을 가진 에셋에서 같은 이름의 슬롯을 한 번에 찾아 실제 머티리얼로 교체할 때 사용하기 좋습니다.



### 기능

- **FBX 스타일 머티리얼 리매핑**
  현재 슬롯에 들어있는 머티리얼의 `Material.name`을 키로 사용해 같은 이름의 슬롯을 한 번에 묶어 처리합니다.

- **동일 슬롯 이름 일괄 적용**
  예를 들어 여러 슬롯이 `Metal`이라는 더미 머티리얼을 사용 중이라면, `Metal` 키에 실제 머티리얼을 한 번만 지정해 모든 `Metal` 슬롯을 교체할 수 있습니다.

- **Prefab Asset 직접 수정**
  씬 인스턴스가 아니라 Project 창의 Prefab Asset을 대상으로 작업합니다.

- **안전한 Prefab 편집 방식**
  Unity의 `LoadPrefabContents` / `SaveAsPrefabAsset` 방식을 사용해 Prefab Asset을 불러오고 저장합니다.

- **하위 Renderer 자동 스캔**
  Prefab 내부의 모든 하위 Renderer를 자동으로 검사합니다.

- **MeshRenderer / SkinnedMeshRenderer 지원**
  Unity의 Renderer 기반으로 슬롯을 검사하므로 일반 MeshRenderer와 SkinnedMeshRenderer 모두 처리할 수 있습니다.

- **슬롯 개수 표시**
  각 키가 몇 개의 머티리얼 슬롯에 영향을 주는지 개수로 표시합니다.

- **드래그 앤 드롭 지원**
  Project 창의 Prefab Asset을 툴 창으로 드래그 앤 드롭해 바로 지정할 수 있습니다.

- **다국어 UI 지원**
  **한국어, 영어, 일본어** UI를 지원합니다. 기본 언어는 한국어입니다.

- **Editor-only 구조**
  에디터 전용 툴이며, 런타임 빌드에는 영향을 주지 않습니다.



### 요구 사항

- Unity **2022.3** 이상
- Project 창에 존재하는 Prefab Asset
- 머티리얼이 할당된 Renderer 또는 SkinnedMeshRenderer
- Unity Editor 전용 사용
- 별도 VPM 의존성 없음



### 사용 방법

#### 기본 사용법

1. 메뉴에서
   **Iyan-Kim > Tools > Prefab Material Remapper** 를 엽니다.

2. 툴 창에서:
   - **프리펩 에셋**에 Project 창의 Prefab Asset을 지정합니다.
   - 또는 드롭 영역에 Prefab Asset을 드래그 앤 드롭합니다.

3. **슬롯 스캔** 버튼을 클릭합니다.

4. Prefab 내부의 Renderer들이 가진 현재 머티리얼 슬롯 이름이 키 목록으로 표시됩니다.

5. 각 키 옆의 머티리얼 필드에 교체할 실제 머티리얼을 지정합니다.

6. **프리펩 에셋에 적용** 버튼을 클릭합니다.

7. 지정한 키와 이름이 같은 모든 머티리얼 슬롯이 선택한 머티리얼로 교체됩니다.



### 옵션 설명

- **프리펩 에셋**
  리매핑을 적용할 Prefab Asset입니다.
  씬에 배치된 인스턴스가 아니라 Project 창의 프리팹 에셋을 지정해야 합니다.

- **드래그 앤 드롭 영역**
  Project 창의 Prefab Asset을 끌어다 놓아 작업 대상을 지정하는 영역입니다.
  프리팹이 아닌 오브젝트는 처리 대상이 아닙니다.

- **슬롯 스캔**
  Prefab Asset 내부를 불러와 모든 하위 Renderer의 `sharedMaterials`를 검사합니다.
  각 슬롯의 현재 머티리얼 이름을 기준으로 키 목록을 만듭니다.

- **키**
  현재 슬롯에 들어있는 머티리얼의 `Material.name`입니다.
  같은 이름을 가진 슬롯들은 같은 키로 묶입니다.

- **개수**
  해당 키가 Prefab 내부에서 몇 개의 머티리얼 슬롯에 사용되고 있는지 표시합니다.

- **머티리얼 필드**
  해당 키에 대응하여 새로 적용할 머티리얼을 지정하는 필드입니다.
  비워둔 키는 적용 시 변경되지 않습니다.

- **프리펩 에셋에 적용**
  지정된 머티리얼 매핑을 Prefab Asset에 저장합니다.
  적용 후 변경된 슬롯 개수를 결과 창에서 확인할 수 있습니다.

- **Language / 언어 / 言語**
  창 하단에서 UI 언어를 선택할 수 있습니다:
  - 한국어
  - English
  - 日本語



### 팁

- 안정적인 리매핑을 위해 FBX에서 가져온 더미 머티리얼 이름을 유지하는 것이 좋습니다.

- `Metal`, `Body`, `Glass`, `UV1`처럼 슬롯 구분용 이름을 가진 머티리얼을 유지해두면 나중에 한 번에 교체하기 쉽습니다.

- 한 번 실제 머티리얼로 교체한 뒤에는 키가 새 머티리얼 이름으로 바뀔 수 있으므로, 다시 리매핑할 계획이 있다면 원본 더미 머티리얼 구조를 별도로 보관하는 것이 좋습니다.

- VRChat 아바타 의상처럼 같은 슬롯 이름이 여러 Renderer에 반복되는 프리팹에서 특히 유용합니다.

- 씬 인스턴스를 대상으로 하지 않고 Prefab Asset을 직접 수정하므로, 작업 전에 Git 또는 백업으로 변경 사항을 관리하는 것을 권장합니다.

- 스캔 결과에서 개수가 큰 키는 여러 슬롯에 동시에 영향을 주므로 적용 전 지정한 머티리얼이 맞는지 한 번 더 확인하세요.



### 문제 해결

- 프리펩 에셋을 지정했는데 오류가 표시됩니다
  - Project 창의 Prefab Asset을 선택했는지 확인하세요.
  - 씬에 배치된 프리팹 인스턴스는 대상이 아닙니다.
  - Prefab Asset이 아닌 일반 GameObject는 처리할 수 없습니다.

- 슬롯을 찾지 못했습니다
  - Prefab 내부에 Renderer 또는 SkinnedMeshRenderer가 있는지 확인하세요.
  - Renderer의 머티리얼 슬롯에 머티리얼이 할당되어 있는지 확인하세요.
  - 머티리얼 슬롯이 비어 있으면 키로 등록되지 않습니다.

- 적용할 내용이 없다고 표시됩니다
  - 스캔된 키 목록에서 교체할 머티리얼을 하나 이상 지정했는지 확인하세요.
  - 머티리얼 필드가 모두 비어 있으면 적용할 변경 사항이 없습니다.

- 원하는 슬롯이 교체되지 않습니다
  - 키는 현재 슬롯에 들어있는 `Material.name`을 기준으로 합니다.
  - 머티리얼 파일 이름과 실제 `Material.name`이 다른지 확인하세요.
  - 이미 다른 머티리얼로 교체된 슬롯은 기존 더미 머티리얼 이름으로 다시 매칭되지 않을 수 있습니다.

- 씬의 오브젝트가 바로 바뀌지 않습니다
  - 이 툴은 Prefab Asset을 수정합니다.
  - 씬 인스턴스에 override가 있거나 갱신이 늦는 경우, 프리팹을 다시 선택하거나 씬을 새로고침해 확인하세요.
