# Face Shadow SDF Generator

`Face Shadow SDF Generator`는 FBX 메쉬를 불러와 3D 뷰와 UV를 기준으로 스타일라이즈드 그림자 맵을 생성하는 데스크톱 툴입니다.  
하나의 메쉬만 처리하는 경우뿐 아니라, 하나의 UV 타겟이 여러 메쉬로 나뉘어 있는 경우에도 멀티 메쉬 선택으로 함께 작업할 수 있습니다.

이 툴은 단순히 UV 이미지만 보고 결과를 만드는 방식이 아니라, 실제 메쉬 형태와 현재 3D 프리뷰 방향을 기준으로 결과를 생성합니다.  
또한 UV 선택, 수동 브러시 보정, 반대 방향 조명 재베이크, RG 패킹 출력까지 한 워크플로 안에서 처리할 수 있습니다.


## 기능

- **FBX 불러오기**
  Blender를 백엔드로 사용해 FBX의 메쉬, 노멀, UV, 재질 정보를 읽어옵니다.

- **단일 메쉬 / 멀티 메쉬 선택**
  하나의 메쉬만 선택할 수도 있고, 같은 UV 타겟을 공유하는 여러 메쉬를 함께 선택할 수도 있습니다.

- **UV Map 선택**
  여러 UV 레이어가 있는 경우 원하는 UV Map을 선택할 수 있습니다.  
  UV는 하나지만 재질별로 겹친 레이아웃인 경우에도 분리된 UV 옵션으로 표시할 수 있습니다.

- **3D 뷰 기반 베이크**
  현재 3D 프리뷰 방향을 기준으로 그림자 맵을 생성합니다.

- **UV 아일랜드 선택**
  필요한 UV 섬만 선택해서 그 영역만 작업할 수 있습니다.

- **수동 브러시 보정**
  `Dark Shadow`, `Light Accent`, `Erase Feature Paint` 모드로 직접 디테일을 추가하거나 지울 수 있습니다.

- **브러시 좌우 복사**
  `Mirror Feature Paint` 버튼으로 수동으로 칠한 내용을 UV X축 기준 반대편에 복사할 수 있습니다.

- **반대 방향 조명 결과 생성**
  `flipped.png`는 단순 좌우 반전이 아니라, 반대 방향 조명으로 한 번 더 베이크한 결과입니다.

- **RG 패킹 출력**
  `rg.png`에 `R = main`, `G = flipped` 형태로 패킹된 결과를 출력합니다.

- **투명 배경 출력**
  UV 바깥쪽을 알파 0으로 내보낼 수 있습니다.

- **다국어 UI**
  English, 한국어, 日本語 UI를 지원합니다.


## 요구 사항

- Windows
- Blender 설치
- FBX에 메쉬와 UV 정보가 포함되어 있어야 함

Blender 경로는 앱 내부에서 지정하고 저장할 수 있습니다.


## 출력 파일

- `main.png`
  - 기본 생성 결과

- `flipped.png`
  - 반대 방향 조명으로 다시 생성한 결과

- `rg.png`
  - `R = main`, `G = flipped`

- `mask.png`
  - 작업 / 출력 마스크

- `asym.png`
  - `main`과 `flipped`를 기반으로 만든 파생 결과


## 사용 방법

### 기본 사용법

1. 프로그램을 실행합니다.
2. Blender 경로가 자동으로 잡히지 않으면 `blender.exe`를 지정합니다.
3. 작업할 FBX를 선택합니다.
4. `Load FBX`를 눌러 메쉬를 불러옵니다.
5. 메쉬 목록에서 작업할 메쉬 또는 메쉬 그룹을 선택합니다.
6. `UV Map`에서 사용할 UV 옵션을 선택합니다.
7. 3D 프리뷰에서 작업 방향을 확인합니다.
8. 필요하면 `UV Select`에서 UV 아일랜드를 선택합니다.
9. 필요하면 수동 브러시로 디테일을 보정합니다.
10. `Generate`를 눌러 결과를 생성합니다.
11. `main`, `flipped`, `rg` 등을 확인합니다.
12. `Export Maps`를 눌러 파일을 저장합니다.


### 처음 사용할 때 추천 순서

1. `4K` 해상도로 시작합니다.
2. `Balanced` 프리셋으로 한 번 생성합니다.
3. 전체 방향이 맞는지 먼저 확인합니다.
4. UV 선택으로 범위를 줄입니다.
5. 마지막에 브러시로 부족한 부분만 보정합니다.

## 주요 옵션 설명

### Mesh Selection

- **Mesh List**
  불러온 메쉬 목록입니다. 이름 기준 A-Z로 정렬됩니다.

- **멀티 선택**
  여러 메쉬가 하나의 작업 타겟을 이루는 경우 함께 선택할 수 있습니다.

- **UV Map**
  현재 메쉬 또는 선택된 메쉬 그룹에서 사용할 UV 옵션입니다.


### UV Selection

- **Select All UV**
  현재 보이는 UV 아일랜드를 모두 선택합니다.

- **Clear UV Selection**
  현재 UV 선택을 모두 해제합니다.

- **Use selected UV islands**
  선택한 UV 아일랜드만 생성에 사용합니다.


### Manual Feature Brush

- **Edit mode**
  - `Select UV Islands`
  - `Place Dark Shadow`
  - `Place Light Accent`
  - `Erase Feature Paint`

- **Brush size %**
  수동 브러시 크기입니다.

- **Mirror Feature Paint**
  현재 칠한 내용을 반대편 UV에 복사합니다.

- **Clear Feature Paint**
  수동으로 칠한 내용을 모두 삭제합니다.

- **Painted pixels**
  현재 칠해진 픽셀 수를 대략적으로 표시합니다.


### UV Display

- **Wire width**
  UV 선 굵기입니다. 프리뷰에만 영향을 줍니다.

- **Wire color**
  UV 선 색상입니다. 프리뷰에만 영향을 줍니다.


### Lighting Presets

- **Balanced**
  가장 무난한 기본 설정입니다.

- **Defined**
  좌우 대비를 더 강하게 줍니다.

- **Dramatic**
  더 강한 방향성과 대비를 줍니다.

- **Extreme**
  매우 강한 스타일라이즈드 대비를 줍니다.


### Bake / Output

- **Resolution**
  `512`, `1K`, `2K`, `4K`, `8K`, `16K`

- **Bake contrast**
  밝은 영역과 어두운 영역의 대비를 조정합니다.

- **Bake ambient**
  그림자 쪽의 바닥 밝기를 조정합니다.

- **Light X / Y / Z**
  조명 방향과 기여도를 조정합니다.

- **Bake smoothing**
  결과를 부드럽게 만드는 스무딩입니다. 기본값은 `0`입니다.

- **UV edge padding**
  UV 경계 처리 강도입니다.  
  음수는 경계 안쪽 문제를 줄이는 데 유용할 수 있습니다.

- **Feature strength**
  수동 브러시 보정이 최종 결과에 얼마나 강하게 들어갈지 결정합니다.

- **Feature blur**
  수동 브러시 보정이 최종 생성 단계에서 얼마나 퍼질지 결정합니다.  
  이 값은 UV 페인트 프리뷰에는 적용되지 않습니다.

- **Transparent outside UV**
  UV 바깥을 알파 0으로 출력합니다.

- **Anime feature shadows**
  수동 브러시 보정을 결과에 반영할지 결정합니다.

- **Use current 3D view**
  현재 3D 뷰 방향을 생성 기준으로 사용합니다.

- **Reset 3D View**
  3D 프리뷰 방향을 초기화합니다.


### Advanced Layers

- **Layer count**
  중간 생성 레이어 수입니다. 짝수여야 합니다.

- **Growth intensity**
  레이어 확장 강도입니다.

- **Horizontal growth**
  가로 방향 퍼짐 강도입니다.

- **Vertical growth**
  세로 방향 퍼짐 강도입니다.

- **Blend mode**
  레이어를 합치는 방식입니다.
  - `ordered_max`
  - `max`
  - `weighted`

- **SDF radius**
  SDF 변환 반경 크기입니다.

## 팁

- 먼저 자동 생성 결과를 보고, 그다음 브러시 보정을 하는 편이 더 안정적입니다.
- `flipped`는 단순 이미지 반전이 아니므로, UV 비대칭 구조에서도 사용할 수 있습니다.
- 브러시로 양쪽에 같은 디테일을 주고 싶다면 `Mirror Feature Paint`를 활용하는 편이 빠릅니다.
- 멀티 메쉬 작업 시에는 선택한 메쉬들이 같은 UV Map을 공유하는지 먼저 확인하는 것이 좋습니다.
- 최종 결과만 고해상도로 생성하고, 작업 중에는 `2K` 또는 `4K`를 사용하는 것이 효율적입니다.


## 문제 해결

- **메쉬를 선택했는데 생성이 안 됨**
  - 선택한 메쉬들이 공통 UV 옵션을 공유하는지 확인하세요.

- **UV 경계에 이상한 어두운 선이 생김**
  - `UV edge padding`을 더 음수로 내려보세요.
  - `Bake smoothing`을 약간만 올려보세요.

- **결과가 너무 약함**
  - `Defined`, `Dramatic`, `Extreme` 프리셋을 사용해 보세요.
  - `Bake contrast`와 `Feature strength`를 올려보세요.

- **결과가 너무 강함**
  - `Bake contrast`를 낮추고 `Bake ambient`를 올려보세요.

- **작업이 느림**
  - 먼저 낮은 해상도로 작업하고 마지막에만 고해상도로 생성하세요.
